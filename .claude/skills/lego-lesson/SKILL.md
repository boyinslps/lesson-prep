# 樂高課程製作（lego-course）

**先讀完整規範**：`D:\自動化教案生成工作流\引導規範\樂高課程設計規範.md`（17 條老師已定規則、S1～S9 流程、自我檢核清單、Python 寫法）。這個檔不重複內容，只是入口與提醒。

## 開工前（一定要做）
1. 讀規範 §1（固定規則）與 §3（老師給過的指導）。
2. 讀 `D:\LEGO 競賽\lego-course\L02_規劃.md` 與 `L02_審查紀錄.md` 當樣板；`L02/index.html` 當版型樣板（複製步驟結構，不重做引擎）。
3. 讀記憶 `project_lego_course.md`。
4. 這節要用的官方頁面**實際打開看**，備份到 `官方資料備份/`。不憑記憶寫官方內容。

## 流程（每階段結束把狀態寫在 `L0N_規劃.md`）
1. 官方資料備份 → 2. 寫 `L0N_規劃.md`，**停下來等老師確認**（已定的規則不再問）→ 3. 蓋 `L0N/index.html`（每零件三頁、字少、圖優先、進階題、收拾步驟、老師欄收合）→ 4. Python 切換版（`data-mode`）→ 5. 在 `spike-sim` 實測並看畫面，不符時**修模擬器**（官方為準）→ 6. 三方審查（專家審認知負荷／鷹架／充分性）→ 7. 驗證頁面 → 8. 老師說推才推 → 9. 日誌與記憶。

## 最容易犯的錯（L02 都犯過）
- Python 專屬內容沒標 `data-mode="py"` → 積木版看到 Python。
- 寫了會出聲的操作（教室電腦沒聲音）→ 改亮燈或看數字。
- 學生頁出現簡體字、年級字樣、設計說明、emoji、姓名。
- 把沒在真機驗證的事寫成確定 → 要列「待真機確認」。
- 照模擬器改學習單 → 應該修模擬器。
- 專家審查只看規範字面 → 要審學理。
- 寫了「分享＋收納」「帶走一句話」→ 這系列不要。
- 沒問就做影片、沒說推就推。

## 交付前
逐條跑規範 §4 自我檢核，回報時分開寫：做了什麼、驗證了什麼、**沒驗證什麼**、有沒有推。收尾寫職涯日誌（全域 CLAUDE.md）。
