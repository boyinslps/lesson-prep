# 特教支持：查證（特殊生版）

給理解較慢的特殊生。分成兩頁：**複習**（慢慢教、有影片、即時回饋）和**作答**（像五上 L01：多則訊息選真假，最後送出）。全程不用寫字。

## T01 查證複習（`T01_查證複習/`，不送出資料）
一頁一件事，按「下一步」。
- 第 1 回（全程引導，影片攤開）：看訊息 → 選關鍵字（選哪些字都算對，最多 3 個）並按「複製」，複製的就是她選的字＋查核→ 到 Google 貼上 → 找查核機構 → 智慧鏡頭 → 看標籤 → 選真/假。
- 第 2 回（同流程，影片也攤開）：微波爐。
- **快問快答**：3 則（蜂蜜、牙膏、冰水），選了**馬上告訴你對不對**，答錯可重選，3 則都對才能繼續。
- 結尾有「去作答」按鈕。
- 老師定案：**AI 摘要不叫她跳過**，可以讀，但要點進查核機構報告確認；以三年級標準看待。

## T02 查證作答（`T02_查證作答/`，送出）
- 8 則訊息（真 3、假 5，約一節課）：每則有「複製關鍵字」「打開 Google」，圖片可用智慧鏡頭；選「真的／假的」。
- 最上面有識別列（年級／班級／座號，沿用 `wk_identity`），送出前 `confirm`，沒填好或失敗會彈出提醒視窗。
- 送出到 Firestore `submissions`（worksheetId `sp-T02`，lessonPath `special/T02`），題型全部 `score`，`accuracyRate` 由頁面算；內嵌 `grading-spec`（base 100／floor 80，每題 3～4 分）。已內嵌靠椅子關卡。
- **保存（寫不完可以繼續）**：每次選答案，約 0.7 秒後自動存到雲端 `studentWork/sp-T02__年-班-座__draft`（要先填好年級、班級、座號）；也有「存起來」按鈕。下次填同樣號碼，會出現「繼續上次的紀錄」（或按「讀取上次紀錄」）；同一台電腦另外還有瀏覽器本機保存。送出後鎖定，不再存草稿。2026-10-27 用真實 Firestore 測過存／讀，測試資料已刪。
- T01 複習只有本機（瀏覽器）保存，同一台電腦重新整理會停在原步驟；沒有雲端保存。
- 送出成功才顯示每題答案、說明、查核報告連結與完成獎勵（打字英雄）；送出後鎖定不能改。
- **沒做**：`#admin` 教師模式（公布答案／預覽學生）——答案內建在頁面裡。
