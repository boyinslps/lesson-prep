# 軌跡設計：事實與意見的區分與驗證

- **起點**：學生在台南生活，常接觸在地美食、景點的網路資訊（如食記、評論、旅遊文），但通常照單全收，無法分辨哪些是客觀描述、哪些是主觀感受，更常誤以為「寫得像事實的就是真相」。
- **目標**：產出「標註事實與意見的長篇分析文本」；帶走的能力為**「先區分再驗證：能拆解資訊中的主觀感受與可查證的客觀陳述」**。
- **最大落差**：從「直覺相信文字」到「認知『事實句』不等於『真的』，而是『可以被驗證真假』的陳述」。
- **里程碑**：
  1. 能用比喻區別短句中的事實與意見。
  2. 釐清「錯誤的事實句仍是事實句」的迷思（可被驗證，驗證真假）。
  3. 能在長篇文章中，獨立找出並畫線標示事實句與意見句。

# 課堂活動展開

### 1. 開場（G1 製造勢能差 ＋ G7 在地化）
- **狀態轉移**：無動機 → 發現同一個在地事物竟有截然不同的說法，產生分辨的需求。
- **引導動作**：並排展示關於台南「文章牛肉湯」的兩段真實網路資訊。
  - A（食記大推）：「文章牛肉湯是我目前吃到台南第一名的牛肉湯！第一口就愛上！」
  - B（在地人抱怨）：「不懂為什麼都要去文章，身為台南人吃牛肉湯從來沒排過隊。」
- **設計提問**：「明明是同一家店，為什麼 A 說天下第一，B 卻覺得不值得排隊？如果你要去吃，你該相信誰？」
- **收攏**：引導學生發現，這兩句話都是「個人感覺」，而不是店家的真實狀況。

### 2. 解密（G3 具象化抽象）
- **狀態轉移**：對「事實」與「意見」概念模糊 → 擁有可預測與分類的心像。
- **引導動作**：給出兩個的比喻工具。
  - **事實（Fact）＝「溫度計 / 尺」**：有刻度、大家看都一樣、可以測量或找證據查證（例如：今天氣溫25度）。
  - **意見（Opinion）＝「穿幾件衣服」**：每個人的感覺、口味、喜好都不一樣，沒有絕對標準（例如：今天天氣很舒服）。
- **設計提問**：「如果你拿『尺』去量這句話，量得出對錯嗎？量得出的就是事實，量不出、只能問你覺不覺得的，就是意見。」

### 3. 示範與挑戰（G6 預測—驗證迴圈）
- **狀態轉移**：聽懂概念 → 能主動套用比喻來判斷短句。
- **引導動作**：展示幾個關於台南景點/美食的短句，先請學生用手勢投票（比溫度計或比衣服），並說出理由，再揭曉解答。
  - 題目一：「文章牛肉湯創立於民國83年。」（預測：溫度計，可以查證營業登記）
  - 題目二：「文章牛肉湯的牛腩湯超級好喝。」（預測：衣服，口味因人而異）

有那些常見的詞彙可以分辨事實和意見
「數字與名稱」： 引導學生找出句中的地點（中西區、善化）、長度（1.5 公里）、食物名稱（小卷米粉、牛肉湯）。這些是可以查證的，屬於事實。
「形容詞與情緒」： 尋找帶有情感色彩的詞彙，如「最有魅力」、「最棒」、「令人驚艷」、「幸福」、「白費」，這些都是個人的感受，屬於意見。
「表達個人想法的句子」：我覺得、我認為....

互動練習題 出多個句子讓學生分類 拖曳到正確分類 保留教師公布答案 firebase

### 4. 承接與釐清（G2 接舊橋新 ＋ G6 預測—驗證迴圈）
- **狀態轉移**：以為事實就是「真的」 → 認知到「事實句 ≠ 真相」，而是「可被驗證真假的陳述」。
- **引導動作**：拋出一個震撼彈短句，逼出迷思。
  - 題目三：「台南孔廟建於西元 2024 年。」
  - **設計提問**：「請問這是事實還是意見？（預測）」
  - （學生通常會回答「意見」，因為它是錯的。）
- **釐清迷思**：這句話是假的，但它依然是「事實句」！因為你可以拿「溫度計（歷史資料）」去查證它。**「看起來像是事實，不代表它就是真的。事實句的意思是『它開放讓你驗證真假』。」**

### 5. 任務（G4 降低起步門檻 ＋ G5 讓目的地可檢核）
- **狀態轉移**：會判斷短句 → 能在真實長篇文章中獨立畫線區分。
- **引導動作**：
- **設計提問**：這篇文章裡把事實跟意見混在一起寫了，請你當偵探把他們拆開。
- **通關條件與自我檢核**：完整畫出文章中的意見與事實

### 6. 收束（G9 產出—展示—回饋—再優化）
- **狀態轉移**：完成任務 → 透過同儕檢驗確認邏輯，帶走可遷移的能力。
- **引導動作**：同桌交換文章，互相檢查對方畫的藍線（事實句）。
- **回饋句型**：「我同意這句是事實句，因為我們可以去查證……」或「我覺得這句應該是意見句，因為……」。
- **命名能力遷移**：後看到任何新聞或廣告，先區分它是事實還是意見，然後去驗證那個事實是真是假。
