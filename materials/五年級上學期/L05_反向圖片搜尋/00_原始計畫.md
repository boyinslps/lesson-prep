# 原始計畫段落 · W4-6（反向圖片搜尋）

第 4-6 週（3 節）
這個資訊和照片可以相信嗎？我能用什麼方法和工具查證，並整理成可信賴的文件？
1.來源評估（作者、出處、日期、目的）。
2.橫向閱讀與交叉比對。
3.反向圖片搜尋（升級三年級以圖搜尋）、舊圖新用辨識。
4.Google Docs 查證調查文件排版與來源標註。
1.能檢視資訊的作者、出處、日期與可信度。
2.能運用橫向閱讀，離開原網頁查找其他來源驗證。
3.能操作反向圖片搜尋，辨識圖片被移花接木或舊圖新用。
4.能運用 Google Docs 統整查證成果，完成圖文調查文件並標註來源。
1.示範「來源評估四問」：誰寫的、哪裡來、什麼時候、為什麼，查找官方來源比對。
2.複習以圖搜尋並升級為反向圖搜，揭穿「舊照片當新事件」案例。
3.小組選定一則校園安全謠言，完成來源評估與反向圖搜的完整查證。
4.用 Google Docs 整理謠言、查證過程、正確資訊與來源清單，完成圖文排版。
1.能運用來源評估、橫向閱讀與反向圖片搜尋完成一則謠言的查證。
2.能在 Google Docs 完成查證文件，包含謠言內容、查證歷程、正確資訊與來源標註。
1.MyGoPen、衛福部、165 全民防騙網等查證網站
2.Google Docs
3.教師自編教學資源。
