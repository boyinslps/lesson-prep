# 賀卡創作營：新 Firebase 專案設定步驟

> 這 6 個頁面（C00 目錄＋C01～C05）共用一個新的 Firebase 專案，跟四、五年級學習單的 pcclass-94300 分開。
> 還沒設定前，頁面照常可用，學生寫的東西**只存在那台電腦**（頂端顯示「只存在這台電腦」）。

## 1. 建立專案（約 3 分鐘）

1. 打開 <https://console.firebase.google.com/>，用老師帳號 `boyin0304@slps.tn.edu.tw` 登入。
2. 「新增專案」→ 名稱例如 `card-contest` → Google Analytics 可以關掉 → 建立。

## 2. 開啟登入方式

左邊「Build（建構）→ Authentication」→「開始使用」→「登入方式」，啟用兩個：

| 登入方式 | 用途 |
|---|---|
| **匿名** | 學生不用帳號，填年級／班級／座號就能存檔 |
| **Google** | 老師在目錄頁 `#admin` 看全部學生的進度（支援電子郵件選老師帳號） |

同一頁「設定 → 已授權的網域」，按「新增網域」加入：

- `boyinslps.github.io`（學生網頁）
- `127.0.0.1`（在工作台本機預覽時用）

## 3. 建立資料庫

左邊「Firestore Database」→「建立資料庫」→ 位置選 **asia-east1（台灣）** →「以正式版模式啟動」。

建立好後點上方「規則」分頁，把本資料夾的 **`firestore.rules` 整份貼上** → 發布。

規則內容摘要：

- 學生（匿名登入）只能讀寫 `cardWork/年級-班級-座號` 這一份，**不能一次列出全部**。
- 只有老師帳號可以列出全部、刪除。
- 每份資料只能有固定欄位（年級、班級、座號、L1～L5），年級限 3～6、班級 1～20、座號 1～40。

## 4. 拿到網頁設定，交給 Claude

左上角齒輪「專案設定」→ 往下「你的應用程式」→ 點 `</>`（網頁）→ 暱稱隨意 → 註冊。
畫面會出現一段：

```js
const firebaseConfig = {
  apiKey: "…",
  authDomain: "…",
  projectId: "…",
  storageBucket: "…",
  messagingSenderId: "…",
  appId: "…"
};
```

把這段貼給 Claude，請它把 6 個頁面裡的 `var FB_CONFIG = null;` 換成這段設定（apiKey 是公開設定值，安全靠上面的規則）。

## 5. 測試

1. 打開任一節，頂端填年級／班級／座號，打幾個字 → 右上角變成「已存到雲端 時:分」。
2. 換一台電腦（或無痕視窗）填同樣的年級／班級／座號 → 剛剛寫的會出現。
3. 打開目錄頁，網址後面加 `#admin` → 「老師登入並讀取」→ 看到學生列表。

## 已知限制

- 學生只靠年級／班級／座號識別，**知道別人座號的人可以改寫別人的資料**（和四、五年級的 studentWork 相同取捨）。這班只有 8 人、在電腦教室由老師看著用，風險低；若要更嚴，可再加一組 4 位數密碼。
