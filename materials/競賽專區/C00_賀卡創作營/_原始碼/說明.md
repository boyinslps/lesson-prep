# 賀卡創作營頁面原始碼

六個頁面（C00 目錄、C01～C05）共用同一份 `common.css`、`common.js`、`sprite.svg`（SVG 圖示與小機器人）。
每頁的內容在 `c00.html`～`c05.html`，用 `<!--@title-->`、`<!--@accent-->`、`<!--@body-->`、`<!--@pre-->`、`<!--@post-->` 分段。

重新產生成品：

```
工作台\runtime\python\python.exe materials\競賽專區\C00_賀卡創作營\_原始碼\build.py        （全部）
工作台\runtime\python\python.exe materials\競賽專區\C00_賀卡創作營\_原始碼\build.py C03    （只做第 3 節）
```

- 改共用的東西（樣式、存檔、圖示）→ 改這裡再 build，六頁一起更新。
- Firebase 設定在 `common.js` 第一行 `var FB_CONFIG`。
- 直接改成品 html 也可以，但下次 build 會被這裡的版本蓋掉。
