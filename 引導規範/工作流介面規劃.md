# 視覺化工作流介面規劃（已實作 · 與程式一致）

> 本文件描述**已落地的實作**（`工作台/`），與 `server.py`、`web/index.html` 保持一致。
> 定位：Claude Code／Gemini 做 AI 生成；面板負責**看 · 勾 · 存**；檔案當兩邊的橋。

---

## 1. 架構（已實作）

```
工作台/
├── runtime/python/          # 免安裝 portable Python 3.12.8（純 stdlib，無 pip）
├── server.py                # 本機伺服器（http.server，port 8770）
├── web/index.html           # 面板（單頁，fetch 呼叫 server API）
├── 啟動工作台.bat            # 雙擊啟動（ASCII 內容，避開 cmd 中文編碼問題）
├── config.json              # AI 設定（首次儲存後生成）
└── _示範資料備份/            # 清掉的示範資料（可還原/刪除）
                             # ↑ 讀寫 ../materials/ 與 ../引導規範/
```

- **技術選擇**：系統無 Python/Node，改用 **portable Python embeddable**（解壓即用、免系統管理員）。伺服器只用標準庫：`http.server` 服務、`urllib` 代理 Gemini、`subprocess`→PowerShell 呼叫 PowerPoint COM 轉 pptx 縮圖。

## 2. 伺服器 API（server.py）

| 方法 | 路由 | 功能 |
|---|---|---|
| GET | `/api/tree` | 掃 `materials/` → 專案／節次／每節 6 階段狀態（依檔案存在推導） |
| GET/POST | `/api/file` | 讀／寫 ROOT 內任一檔（含**鷹架 01 等可編輯存回**）；含 path traversal 防護 |
| GET/POST | `/api/settings` | 讀／寫 `config.json`（Gemini 端點/模型/Key） |
| POST | `/api/gemini` | 代理 Gemini generateContent（stdlib urllib，讀 config） |
| GET | `/api/gemini-models` | 呼叫 Gemini ListModels，回傳支援 generateContent 的模型清單 |
| POST | `/api/split` | **計畫切分**（專案層級）：Gemini 依《工作流程規範》產 00_節次總表 → 建各節資料夾 |
| POST | `/api/extract` | 匯入課程計畫檔抽文字：md/txt 直讀、**docx** 用 zipfile、**pdf/doc** 用 Word COM |
| POST | `/api/package-lm` | **打包給 NotebookLM**：建 `_LM包/`（教學內容＋指引＋下載圖片） |
| POST | `/api/crawl` | 爬 03 素材連結：圖片下載本機、影片取縮圖、網站取標題說明 |
| POST | `/api/github-publish` | 單檔發布（PAT＋Contents API）：附到 Classroom 貼文時取網址用 |
| POST | `/api/git-publish` | **整包發布（SSH）**：把某節成品檔（`{年級簡稱}_{節次資料夾名}.html`）＋`assets/` 推到 `pcclass` 的 `g{年級}/L##/`（改名 index.html）→ 回 Pages 網址；成功後把網址同步存進 `materials/_layout.json` 的 `published` 欄位 |
| POST | `/api/drive-upload`／`/api/classroom-publish` | 簡報上傳 Drive、發布到 Google Classroom |
| GET/POST | `/api/pptx` | pptx→PNG 縮圖（PowerPoint COM） |
| GET | `/api/reveal` | 用檔案總管開啟指定資料夾 |
| GET | `/api/guides` | 列 `引導規範/*.md` |

## 3. 面板結構（web/index.html）

- **頂列**：品牌／進度（N 節完成）／專案選單／**✂ 計畫切分**／🔄 重讀／⚙ 設定／◐ 深淺色。
- **左：節次清單**：讀 tree，每節 6 顆管線點（綠＝完成、灰＝未開始）。
- **中：準備管線**（單元層級 **6 階段**）：`鷹架分析 → 關鍵字 → 素材搜尋 → 篩選勾選 → 教學環節 → 成品`；每階段標 `AI`（Claude Code/Gemini）或 `人工`（篩選勾選）。
  - 點階段 → **可編輯 textarea ＋ 💾 儲存**（寫回該階段檔，含鷹架）。
  - AI 階段有 **🤖 用 Gemini 生成**（組 規範＋節次總表＋前階段 為 prompt → 產草稿 → 你看過再存）。
  - **生成鈕旁有「本次前置提示詞」輸入框**：這次生成臨時加在 prompt 最前面（一次性）；長期預設的前置提示詞在 ⚙ 設定裡（`gen_prefix`），兩者會一起前置。
  - 關鍵字階段可**手動增補關鍵字**。
  - **成品階段**：先「🖥 本機預覽」（本機伺服器開啟、驗收互動與素材），再「🚀 發布到 GitHub」（SSH 整包推上 Pages，成功後網址直接顯示在這裡＋存進 `_layout.json`，下次開面板不用重發布就看得到）；另有「📤 發布到 Classroom」。發布分兩段＝**先本機、再 GitHub**（見 `互動教材進階規範.md` §5）。
- **右上：📦 交接包**：兩種方式——① 複製文字送 Claude Code；② **建立 `_LM包` 資料夾**送 NotebookLM。
- **設定**：① AI 端點（**🔌 測試並列出模型** → 模型變下拉清單）；② 直接編輯 `引導規範/*.md` 並寫回。
- **深色模式**：◐ 切換，選擇存 localStorage、重開保留；三態 CSS（system／明示 light／dark）。

## 4. 關鍵設計決定（與早期規劃的差異）

1. **計畫切分是專案層級**，不是單元的第一階段。切分完，節次才在左側長出來。
2. **面板不呼叫 AI 於前端**：所有 AI 走 server 的 `/api/gemini`（前半段接 Gemini；反覆聊天到 Claude Code）。
3. **NotebookLM 打包要把圖爬下來**：LM 不吃外連圖，故 `package-lm` 從素材連結**下載圖片**進資料夾。
4. **影片不進簡報**：頁面清單留只有標題的空白頁提示老師手動放。
5. 檔案存在與否＝管線狀態，所以介面天然能畫出進度。

## 5. 使用流程

1. 雙擊 `啟動工作台.bat` → 瀏覽器開 `http://127.0.0.1:8770`。
2. ⚙ 設定填 Gemini Key → 🔌 測試並列出模型 → 選模型 → 儲存。
3. ✂ 計畫切分：**匯入課程計畫檔（docx/pdf/md/txt）或貼上文字** → Gemini 切分 → 產生節次（左側出現）。
4. 逐節走管線：每階段用 Gemini 生成草稿 → 檢查／編輯 → 儲存；篩選勾選為人工。
5. 交接包送 Claude Code（HTML/調整）或建 `_LM包` 送 NotebookLM（簡報）。
6. 成品回存 `materials/`，在節次自己的成品區預覽與確認、發布。
