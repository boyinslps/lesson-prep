# 教學活動設計規範（引導邏輯通則）

> 這份文件寫的是**過程的邏輯**，不是某個主題的模板。
> 目的：拿到**任何新主題**時，能用同一套「引導思考法」推導出一節／一單元的教學活動。
>
> **使用原則**
> - 以下是**原則 × 設計提問 × 狀態轉移**，不是要照抄的固定段落或固定情境。
> - 文中出現的具體例子一律標「〔例，換主題請重推〕」，只為說明邏輯，**不要當成內容套用**。
> - 需要看真實脈絡的範例與證據時，回查同專案的 `教學風格分析.md`。這份談「怎麼想」，那份談「他做過什麼」。

---

## 1. 核心心智模型：教材是一條「起點 → 目標」的引導軌跡

任何一份教材，本質是**把學習者從一個起始狀態，一步一步搬運到一個目標狀態**。
設計教學活動＝**規劃這條軌跡**：確認兩端、找出中間必經的狀態、為每一次「狀態轉移」設計一個引導動作。

```
起始原點 ──①──▶ 狀態 ──②──▶ 狀態 ──③──▶ … ──▶ 目標
            每個箭頭 = 一次「最小可跨步」+ 一個「引導動作」
```

- **起始原點（origin）**：學習者此刻真實的處境——他已經會什麼、還不會什麼、身上有什麼真實問題或經驗。
- **目標（goal）**：不只是「學會某工具」，而是**一個可展示、能被別人使用的產物** ＋ **一項可命名、可遷移的能力**。
- **中間的引導方式（the path）**：一連串狀態轉移。每一步只跨「學習者當下踮腳搆得到」的距離，並在每一步放一個引導動作，把他推過去。

這條軌跡有**兩個尺度**，用同一套邏輯：
- **專題尺度**（數週）：一個大問題 → 一個完整作品的長弧線。
- **單節尺度**（一節課）：一次能獨立完成的轉移鏈。

> 設計時永遠先問：**「這份教材是把誰、從哪裡、搬到哪裡？中間有哪些他非跨不可的坎？」**

---

## 2. 設計的第一步：先畫出軌跡（定位提問）

動手寫活動前，先用這組提問把軌跡的兩端與骨幹定出來。**答不出來就不要開始寫步驟**。

**定起點**
- 學習者現在已經會什麼？（可掛靠的舊經驗）
- 他身上有什麼**真實、在地、有感**的問題或需求？（軌跡的驅動力來源）
- 對這個主題，他最可能有的**迷思或卡點**是什麼？

**定目標**
- 這條軌跡結束時，會產出**什麼可展示的東西**？（作品）
- 學習者會**帶走什麼能力**？用一句話命名它（能遷移到別的主題）。
- 他要怎麼**知道自己到了**？（可被學習者自己判斷的完成標準）

**定落差與里程碑**
- 起點到目標之間，**最大的認知落差**在哪？（那裡就是要重點鋪橋的地方）
- 這條路可以切成哪幾個**里程碑**？每個里程碑是一個「他做得出來、看得到」的小成果。

> 產出：一張「軌跡草圖」——起點、目標、3～6 個里程碑。之後每一節課負責推進一段。

## 3. 引導的通用操作子（可遷移的引導動作）

這是本規範的核心：把「老師如何在兩個狀態之間推學習者一把」抽象成**九個操作子**。
每個操作子回答同一件事：**從什麼狀態、到什麼狀態、用什麼動作、設計時問自己什麼**。
換主題時，操作子不變，只換內容。

### G1　製造勢能差（開場的拉力）
- **從 → 到**：學習者無動機 → 感到「現狀和理想有落差，我想跨過去」。
- **動作**：讓**目標狀態**與**現在狀態**的差距**可見且有感**——用對比、真實案例衝擊、或一個直指落差的驅動問句。
- **設計提問**：我能不能把「還沒學會 / 問題還在」和「學會之後 / 問題解決」擺在一起讓他一眼看到落差？這個落差跟他的生活有關嗎？
- 〔例，換主題請重推〕危險街景 vs 理想街景並排；「怎樣的○○才能讓大家○○？」

### G2　接舊橋新（不空降新東西）
- **從 → 到**：面對陌生新概念 → 覺得「這只是舊東西的延伸」。
- **動作**：先複習上一步的做法，再**用舊方法解不了的新問題**把新概念自然引出——是「需求」逼出新工具，不是老師憑空塞。
- **設計提問**：學習者上一步會的是什麼？那個方法**卡在哪**，正好需要今天這個新東西來解？
- 〔例，換主題請重推〕「上週我們用○○，但如果要××，有沒有更直接的做法？」

### G3　具象化抽象（承重的比喻）
- **從 → 到**：概念抽象、摸不著 → 有一個能**預測概念行為**的具體心像。
- **動作**：把抽象概念綁定一個學習者熟悉的日常物件或角色。關鍵：比喻要**承重**——它的行為規則要和概念一致，能拿來推理，不只是裝飾。
- **設計提問**：這個概念的「行為規則」是什麼？哪個日常東西**遵守一樣的規則**？用這個比喻去推，會不會推出概念的正確性質？
- 〔例，換主題請重推〕「只能裝一個、新的進來舊的就走」的容器 → 覆寫式變數；「只問一個是非、不成立就跳過」的角色 → 條件判斷。

### G4　降低起步門檻（消滅空白頁）
- **從 → 到**：面對空白、不知從何下手 → 有一個可以直接動手改的起點。
- **動作**：給**半成品**而非零——填空模板、可勾選的選單、可背的口訣、編號好的步驟。讓「從零創造」變成「選擇與修改」。
- **設計提問**：學習者最容易卡在「不知道怎麼開始」的地方是哪？我能給他什麼**半成品或選項清單**，讓他一上手就有東西可改？
- 〔例，換主題請重推〕自我介紹填空句型；效果分類選單；「先做什麼→再做什麼」的步驟骨架。

### G5　讓目的地可檢核（看得見的通關條件）
- **從 → 到**：不確定「這樣算不算對」 → 能自己判斷「我到了沒」。
- **動作**：每個任務配一個**明確的通關條件**（做到什麼才算完成）＋一份**繳交前自我檢查**。成功要能被學習者自己驗證，而不是只有老師知道。
- **設計提問**：學習者要怎麼**不靠老師**就知道自己做到了？完成的樣子能不能用一句話 / 一張清單描述？
- 〔例，換主題請重推〕「每次啟動，○○都要從不同位置出現」；「繳交前：是否３項？內容是否合理？」

### G6　預測—驗證迴圈（把旁觀變成假設）
- **從 → 到**：被動看示範 → 主動對結果下賭注、再檢驗。
- **動作**：在揭曉答案／執行之前，先要學習者**預測會發生什麼、並說出為什麼**，然後才驗證。答錯也有價值——它逼出思考。
- **設計提問**：這一步之前，我能問一個什麼「你猜會怎樣？為什麼？」的問題，讓他先形成假設？
- 〔例，換主題請重推〕「把這一塊拿掉再執行，還會動嗎？為什麼？」；先別動手，盯著看，然後回答三個問題。

### G7　在地化與個人化（相關即擁有）
- **從 → 到**：覺得內容與我無關 → 覺得「這是我的東西」。
- **動作**：**例子**用學習者自己的真實環境；**產物**內嵌學習者自己的資料 / 選擇。相關性帶來投入，個人化帶來擁有感。
- **設計提問**：這個例子能不能換成學習者自己的生活場景？最後的產物裡，有沒有一塊是**他自己填的、獨一無二的**？
- 〔例，換主題請重推〕用學校門口而非通用街景；最終作品裝進學生自選的主題內容。

### G8　給能力的同時給界線（負責任的工具觀）
- **從 → 到**：把強大工具（尤其 AI）當萬能 → 會用、也知道它何時會壞、界線在哪。
- **動作**：每當引入一個有力工具，**同時**教它的失效模式與護欄——查核、隱私、來源。能力與責任一起給，不分開。
- **設計提問**：這個工具**會怎麼出錯**？學習者要守哪條界線？我能不能把「找出它的錯 / 守住界線」也設計成一個活動或加分關卡？
- 〔例，換主題請重推〕教 AI 生成的同時教「它會無中生有，要比對現實」；公開發布前先分「可分享 / 要隱藏」。

### G9　產出—展示—回饋—再優化（讓學習被看見）
- **從 → 到**：做完就結束 → 作品被別人看見、得到具體回饋、據以優化。
- **動作**：軌跡以「公開作品 ＋ 具體且正向的回饋 ＋ 依回饋再優化」收束。學習在社群裡被驗證與精修。
- **設計提問**：作品要給誰看？我能給什麼**回饋句型**讓同儕說得出具體優點與建議（而非「很棒」）？看完之後，怎麼帶一輪優化？
- 〔例，換主題請重推〕「我喜歡○○，因為××」；互玩後記錄問題→修正→再測試。

> 這九個不是流程順序，是**工具箱**。同一個操作子可在一節課用很多次；不是每節都要用滿九個。依軌跡此刻的需要挑用。

## 4. 把操作子串成一節課（節奏，不是硬模板）

一節課＝軌跡上的一小段。與其套固定段落，不如把課想成**幾個「功能位置」**，每個位置只回答三個問題：
**（a）學習者此刻在哪個狀態？（b）這一步要把他帶到哪？（c）用哪個操作子推？**

常見的功能位置（可增、可刪、可換序，依主題與節數調整）：

| 功能位置 | 它負責什麼轉移 | 常用操作子 |
|---|---|---|
| 開場 | 無動機 → 想跨落差 | G1，可搭 G7 |
| 承接 | 陌生 → 掛回舊經驗、由不足引出新題 | G2 |
| 解密 | 抽象 → 有承重心像 | G3 |
| 定向 | 模糊 → 知道今天要到哪、怎樣算到 | G5 |
| 示範 / 探究 | 不會操作 → 跟得上、看得懂關鍵 | G4，穿插 G6 |
| 挑戰 | 被動 → 主動預測與推理 | G6 |
| 任務 | 學過 → 能獨立產出可檢核成果 | G5＋G4，涉工具加 G8 |
| 收束 | 做完 → 被看見、得回饋、再優化 | G9 |

**節奏原則（非硬性）**
- **一次只跨一步**：兩個功能位置之間的認知距離要小到「踮腳搆得到」。落差太大就再切一個里程碑進去。
- **先需求、後功能**：讓「想要」出現在「怎麼做」之前（G2／G1 在 G4 之前）。
- **抽象一定配比喻**（G3），操作一定配可檢核（G5）。
- **涉及強工具就同時給界線**（G8），不延後。
- 第一次使用某工具的那一段，要把**環境門檻**（帳號、平台、存檔、命名規則）當成一個真正的「狀態轉移」放進軌跡——它不是雜務，是必經的坎。

---

## 5. 收束與遷移

一段軌跡走完，除了作品，要讓學習者**帶走可遷移的東西**：
- **把能力命名**：用一句話講出「你剛剛學會的是一種可以用在別處的什麼」（例：不是「學會某積木」，而是「學會用『判斷』讓程式自己做決定」）。
- **指出可遷移點**：問「這個做法還能用在哪個別的問題？」——把單一主題的技能抬升成通用心法。
- **回饋轉自評**：G9 的同儕回饋要導回「我下次會怎麼改」。

---

## 6. 設計者自檢（用提問，不用教條）

寫完一份活動，回頭問自己：
- 我說得出這份教材**把誰、從哪、搬到哪**嗎？中間的坎清楚嗎？
- 起點有沒有一個**真實、在地、有感**的拉力（G1／G7）？
- 每個新東西都**掛在舊經驗、由不足引出**了嗎（G2）？還是我在空降？
- 抽象的地方有沒有**承重的比喻**（G3）？那個比喻經得起用來推理嗎？
- 學習者能不能**不靠我就知道自己到了**（G5）？
- 有沒有至少一個「**先預測再說為什麼**」的時刻（G6）？
- 用到強工具時，**界線與查核**在場嗎（G8）？
- 收尾有沒有讓作品**被看見、得到具體回饋、再優化**（G9）？
- 我有沒有不小心把它寫死在這個主題上？**換一個主題，這套軌跡邏輯還走得通嗎？**

## 7. Few-shot 示範：把邏輯套到全新主題

> 以下範例**刻意選用分析語料裡沒有的主題**，用來示範「同一套引導邏輯，換任何主題都走得通」。
> 重點看**推理過程**（為什麼這樣鋪、用了哪個操作子），不是背下這些內容。
> 生成新教材時，請照這個「先畫軌跡 → 再串操作子」的推理方式，換上你自己的主題重做一次。

### 示範一（完整）：主題「用 Google 試算表幫班級管理班費」

**Step 1 先畫軌跡（§2 的提問）**
- 起點：學生會用鍵盤打字、看得懂數字加減；但沒用過試算表，且覺得「記帳＝大人的事，跟我無關」。迷思：以為要自己一格一格算。
- 目標：產出「班費收支表」，能自動算出結餘；帶走的能力＝**「讓表格幫我自動算，而不是自己算」**（可遷移到成績、統計任何情境）。
- 最大落差：從「手動算」到「公式自動算」的心態轉換。→ 這裡要重點鋪橋。
- 里程碑：①看得懂一張收支表長怎樣 → ②會輸入資料與分類 → ③會用一條加總公式 → ④結餘自動更新、能解讀。

**Step 2 一節課骨架（§4 的功能位置，標出操作子與推理）**
- **開場（G1＋G7）**：秀一張亂記在紙上、算到打結的班費本子 vs 一張一改數字結餘就自動變的表格。〔勢能差：手忙腳亂 vs 一秒算完〕問：「如果每次有人交錢就要重算一次，你想手算還是讓電腦算？」
- **承接（G2）**：複習「上次我們用文件打字」，拋新題：「文件能打字，但它會**幫你算數學**嗎？→ 需要一種會算的紙。」由不足引出試算表。
- **解密（G3）**：比喻——**儲存格＝一格一格的抽屜，公式＝抽屜之間的『管線』**，A 抽屜的錢變了，接了管線的『總和』抽屜會自己跟著變。（承重：能拿來推理「改一格，總和為何自己變」）
- **定向（G5）**：今天通關條件——「隨便改一筆金額，最下面的『結餘』會自己變，而且算對」。
- **示範（G4＋G6）**：編號步驟教輸入與 `=SUM()`。示範前先 **G6 預測**：「我在這格打總和公式，等一下我改上面任一個數字，你猜結餘會怎樣？為什麼？」再驗證。
- **任務（G5）**：給**半成品表格**（已排好欄位：日期／項目／收入／支出），學生只需填 3 筆並套一條加總公式。繳交前自我檢查：☐ 有 3 筆 ☐ 改數字結餘會變 ☐ 檔名＝班級座號。
- **收束（G9）**：兩人互看，用「我發現你的○○，如果××會更清楚」句型回饋；命名能力：「你今天學會的不是『試算表』，是**讓工具替你重算**——以後算成績、統計票數都能用。」

〔註：本主題沒用到 AI，故未觸發 G8；一旦加入「用 AI 幫我想記帳分類」就要同時教查核與隱私。〕

### 示範二（骨架）：主題「認識並判斷『免費貼圖』詐騙訊息」

同一套邏輯，換到資訊素養主題，重點示範 **G8** 如何自然登場：
- 軌跡：起點「常收到轉傳訊息、照單全收」→ 目標「能對一則訊息喊停並查證」＋能力「**先懷疑、再查證**」。
- 開場 G1：並排「真的官方公告」與「幾可亂真的詐騙訊息」，問「你分得出來嗎？」
- 解密 G3：比喻「查證＝當偵探，訊息＝嫌疑犯，不能只聽它自己說」。
- 挑戰 G6：先讓學生**預測**哪則是假的並說理由，再一起查證揭曉。
- 任務 G5＋G8（能力＋界線一起給）：找一則可疑訊息，用「來源？時間？其他地方查得到嗎？」三問查證，並記錄。**界線**：不轉傳未證實訊息；不把個資回填到可疑連結。
- 收束 G9：分享各自查到的案例與判斷依據。

> 兩個示範主題天差地遠，但**軌跡邏輯與操作子完全共用**。這就是本規範要你內化的東西：不是內容，是**搬運學習者的方法**。
