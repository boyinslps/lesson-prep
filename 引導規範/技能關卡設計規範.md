# 技能關卡設計規範（電腦急救站）

> 適用：`技能闖關/levels/` 的每一關。老師說「新增關卡：○○」時，照這份產出。

## 1. 一關只教一個動作

- 一關＝**一個核心動作**（例如「純文字貼上」），不要一次教三件事；相關但不同的動作拆成另一關，用 `prereq` 串起來。
- 學生從進關到過關控制在 **3～5 分鐘**：影片 30～60 秒、練習 1～2 個任務、挑戰 2～3 個任務。
- 挑戰的內容要和練習**不同**（換文字、換位置），避免學生照抄練習。

## 2. 判定原則

- 一定要偵測**真的做了那個動作**（copy／paste 事件、選取範圍、按鍵、上傳的檔案），**不能**只放一個「我完成了」按鈕。
- 網頁偵測不到的操作（檔案總管、存檔）改用「**做完 → 上傳回來**」：比對檔名、內容裡的驗證碼、圖片雜湊。
- 做錯時的提示要說「**哪裡錯＋怎麼補救**」（例：「格式也跟著過來了，按 Ctrl+Z 復原，再改用 Ctrl+Shift+V」），不要只說「錯了」。
- 練習模式（practice）可以用點點底線標出目標、給下一步提示；挑戰模式（challenge）不標、不提示。

## 3. 檔案與命名

```
技能闖關/levels/{代碼}_{名稱}/
  level.json        必要
  assets/           選用：教學.mp4、封面.jpg、要讓學生下載的檔案
```

- 代碼＝類別字母＋兩位內數字（A1、B12），不能重複；停用用 `"enabled": false`，**不要刪資料夾**（舊紀錄要能對得上）。
- 新類別要先加進 `技能闖關/設定.json` 的 `categories`。

## 4. level.json 欄位

| 欄位 | 說明 |
|---|---|
| `code` `title` `category` | 代碼、名稱、類別 |
| `core` | 是否必修（第一階證書的條件） |
| `prereq` | 先修關卡代碼陣列，沒有就 `[]`；不能繞成一圈（build 會擋） |
| `order` | 同類別裡的排序 |
| `summary` | 一句話說這關學什麼（地圖卡片上顯示） |
| `learn.video` `learn.poster` | 影片路徑（相對於關卡頁，如 `assets/教學.mp4`）；還沒做就留空字串 |
| `learn.steps` | 步驟，可用 `<b>`、`<kbd>` |
| `learn.tips` | 小提醒（右鍵替代做法、記憶法） |
| `practice` `challenge` | `{checker, params}`，判定器名稱與參數 |
| `production` | 製作備註：`video`（todo／done）、`videoKind`（web＝網頁可截圖／desktop＝要 computer use）|

## 5. 判定器

寫在 `技能闖關/_原始碼/checkers.js`，介面：`Checkers.名稱(el, params, ctx)`，`ctx.pass()`／`ctx.miss(訊息)`（算一次嘗試）／`ctx.hint(訊息)`。

| 判定器 | 用途 | params |
|---|---|---|
| `selectText` | 拖選、雙擊選詞、Ctrl+A | `passage`、`allText`、`tasks:[{kind:range/word/all, target, say}]`；雙擊題請用英文單字 |
| `copyPaste` | 複製→貼上到文字框；`cut:true` 變剪下 | `passage`、`tasks:[{target, label, say?}]`、`cut`、`srcLabel` |
| `plainPaste` | 純文字貼上 | `richHtml`、`target`、`docHtml`（用 `<span class="slot">` 標貼上位置）、`say1`、`say2` |
| `fileUpload` | 下載／改名／另存後上傳回來 | `file:{name, lines}`（文字檔，自動加驗證碼）或 `file:{src, name, alt}`（圖片，SHA-256 比對）；`rename`（可用 `{grade}{class}{seat}`）；`say:[兩步說明]` |
| `popup` | 處理彈出視窗 | `popups:[cookie, notify, ad, prize, subscribe]`、`shuffle`、`adWait`（秒）、`page:{tab, url, html}` |
| `tabPair` | 開新分頁、切換、關分頁 | `linkText`、`closeTab`；搭配 `site/tab/`（_原始碼/tab.html），新的分頁類關卡可沿用 |
| `tabUrl` | 新分頁複製網址列貼回來 | `linkText`（網址含本次專用 #代碼） |
| `tabReopen` | 關分頁再用 Ctrl+Shift+T 救回 | `linkText` |
| `reload` | 網頁卡住→重新整理 | `say`、`tab`、`url`（重新整理後同分頁回來即過關） |
| `keyTask` | 文字框裡依序完成任務，可規定要用哪個快速鍵 | `text`、`tasks:[{say, key:'ctrl+z\|ctrl+y', cond:{equals:'@original', contains, notContains}, hint, miss}]` |
| `quiz` | 選擇題／拖曳分類（觀念題，少用） | `kind:'choice'`＋`questions:[{q, options, answer, why, wrong}]`；`kind:'bucket'`＋`buckets`、`items:[{t, b, why}]` |

能用既有判定器就不要新寫；真的要新寫，寫成通用的（參數化），並在這張表補一列。

## 6. 教學影片

- 網頁內的動作：`工作台/步驟影片工具`（cdp.ps1 截圖＋render.ps1 合成），夜間可做。
- 桌面／檔案總管／右鍵選單：computer use 截圖後同樣用 render.ps1 合成；**需要老師在場**按允許，夜間不做，列進 PROGRESS.md「錄影待辦」。
- 每支 30～60 秒，紅框＋游標動畫＋一行字卡，結尾停在「換你試試看」。錄影環境用乾淨的示範資料夾，不能拍到私人檔案。

## 7. 新增一關的流程

1. 在 `levels/` 建資料夾、寫 `level.json`
2. `工作台/runtime/python/python.exe 技能闖關/build.py`（有錯會直接停）
3. 預覽（launch.json 的 `skills`）把「練」和「闖」各走一次，確認做錯會提示、做對會過關
4. PROGRESS.md 打勾
