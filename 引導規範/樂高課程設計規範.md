## 2. 製作一節的流程（L02 驗證過的順序）

### S1 先讀官方，不憑記憶
- 實際進官方頁面（`https://spike.legoeducation.com/prime/start/`、Python 說明 `.../help/lls-help-python`）把這一節要用的每一頁看過。
- 備份到 `官方資料備份/`：英文原文、中文導讀、程式卡圖（本機參考，**不放進學生頁、官方照片不進公開 repo**）。
- 官方 App 語言是瀏覽器設定，連結不能指定；若學生要看中文，領箱頁要有設定連結＋勾選，老師欄提醒前一天設好。
- Python 以官方入門頁的**平的寫法**為準（見 §5），再對 `SPIKE_blocks_and_api/` 的 API 參考。

### S2 寫 `L0N_規劃.md`，等老師確認
固定骨架（可直接複製 L02_規劃.md）：
0. 老師已定規則表（把 §1 列進來，加本節新增的）
1. 官方這節教什麼（逐頁看過的結果）
2. 學習單怎麼接官方
3. 50 分鐘怎麼走：**動手 ≥ 30 分鐘**；每步驟分鐘；**砍法**（時間不夠先砍哪裡、被砍的下一堂補）
4. 接口與接線
5. 闖關題草案
6. 本節特有的互動小工具
7. 身分與儲存
8. 要老師決定／確認的清單（連同選項與建議）
9. 下一步

規劃寫完先停，等老師回應再蓋頁。已定的項目用刪除線標「已定」，不要再問第二次。

### S3 蓋頁（`L0N/index.html`，用 `assets/course.js`／`course.css`）
- 每一步一個 `<section class="step">`，屬性：`data-type`（intro／task／quiz／box）、`data-part`、`data-sub`、`data-title`、`data-min`、`data-color`；測驗步驟加 `data-gate`。
- **單頁字少**：基準 21px，每頁正文（不含程式卡、測驗、檢核）約 45～130 字；多的放老師欄。
- 圖優先於字：座標、軸向、動作用 SVG／CSS 圖（例：燈陣座標圖、陀螺儀俯仰／翻滾／轉向動態示意圖）。
- 操作順序照實際順序，同一視窗一次做完；工具用到才教。
- 每個動手步驟：先猜 → 做 → 看結果 → 只改一個地方再看差別 → 勾選檢核。
- 每個程式練習放一個 `.adv` 進階題給做快的人（例：Hello World 顯示英文、馬達轉更多圈、調整速度）；進階題下面不要塞太多步驟。
- 凡是「改程式也要改接口」「先按暫停再拔線」這類容易漏的動作，放在**會發生的那一步旁邊**提醒。
- 時間：每頁 `data-min`，Python 版不同就加 `data-min-py`；所有分鐘加總要等於該節總長，積木版與 Python 版**各自**都要等於。
- 老師欄 `<aside class="t t-head"><details>`：準備清單、時間軸、卡關處理、待確認；測驗頁老師欄只放該頁講法。
- 官方連結用固定分頁名（`target="spike"`），頁面寫「回到官方分頁」，並附重開連結。

### S4 Python 版（同一份教材切換，不另做頁面）
- 頁首 `[積木｜Python]` 開關，`localStorage lc.mode`，網址 `?mode=py` 可指定；同堂可隨時切，**切換不重置進度**（`data-key` 不變）。
- 內容用 `data-mode="block"`／`data-mode="py"`；沒標的兩邊共用。屬性覆寫：`data-title-py`、`data-sub-py`、`data-min-py`。
- 隱藏規則是 CSS（`body:not(.mode-py) [data-mode="py"]{display:none!important}` 與反向）；**新增任何 Python 專屬區塊一定要標 `data-mode="py"`**，否則會在積木版露出來（L02 出過這個錯）。
- 測驗只算當前模式的題目（`inMode()` 過濾）。
- 官方教學只有積木版，所以 Python 頁改成：新增／沿用 Python 專案 → 貼上程式 → 按播放 → 改一個數字再播放。
- 要整理的「單位陷阱」表（每節都補新的一列）：角度 vs 圈、毫米 vs 公分、十分之一度、`-1` 表示沒偵測到、`await` 與不用 `await` 的版本。

### S5 在模擬器實測（`D:\LEGO 競賽\spike-sim`）
- 子代理分組：Python 約 3 組、積木約 2 組，各自照學習單從頭做；回報後**主線程直接修**。
- **官方為準**：學習單的程式在官方 App 能跑，模擬器就必須能跑。不符時**修模擬器**，不要改學習單遷就模擬器；刻意不一致的寫進審查紀錄「沒改（刻意）」。
- 每支學習單程式都要在模擬器跑過，並**看視覺結果**（LED 是否真的 5×5、字會不會捲動、馬達轉向、距離拖曳、力按壓、陀螺儀傾斜），不是只看沒報錯。
- 模擬器改動要另外 commit／推 `robot-quest`；官方零件照片只留本機（`.gitignore`）。

### S6 三方審查，寫進 `L0N_審查紀錄.md`
- **授課教師**（分鐘、卡關、分工、準備清單）、**五年級學生**（看不看得懂、字詞難度）、**數位教材專家**。
- **專家要審學理：認知負荷、鷹架合理性、內容充分性（含動機、遷移）**，並提供學習目標讓審查者判斷夠不夠；不是只對規範字面或技術細節。
- 每條回饋標「已修／沒改（理由）／待實機」，輪次與日期寫清楚。

### S7 驗證頁面（內建瀏覽器，桌面寬度）
見 §4 自我檢核。真機沒測過的東西，頁面不寫成已驗證；列入「待真機確認」。

### S8 發布
- 說推才推（見 §1-17）。推完用線上網址檢查一次（含圖片 200、新功能存在）。
- 新一節：總站課程清單加入、`lego-course/index.html` 目錄加入。

### S9 收尾
- 職涯日誌（見全域 CLAUDE.md）、更新記憶（`project_lego_course.md`）、`README.md` 與 `L0N_規劃.md` 寫進最新決定。

## 5. Python 官方平的寫法（本系列採用）

```python
from hub import port, light_matrix      # 每支程式只 import 這支要用的
import color_sensor
import color
import time

while True:
    if color_sensor.color(port.A) == color.RED:
        light_matrix.show_image(light_matrix.IMAGE_HAPPY)
    else:
        light_matrix.clear()
    time.sleep_ms(50)
```

- 學生程式用 `time.sleep_ms`，不要求 `async/await`、不用 `runloop`；每支程式開頭只 import 自己用到的，並用一句話說明 import 是「借工具」。陀螺儀是 `from hub import motion_sensor`（不是 `import motion_sensor`）。
- 官方寫法在模擬器的處理：`pyrun.js` 把同步 `def` 轉成非同步、程式結束前等背景動作做完，所以 `motor.run_for_degrees`、`light_matrix.write` 不加 `await` 也能跑。**這個行為在真機是否一致尚未驗證**，列入待真機確認。
- 單位：馬達度與度／秒（1 圈＝360）；距離**毫米**、沒偵測到 `-1`；力 `force` 是十分之一牛頓、`pressed` 回 True／False；陀螺儀 `tilt_angles()` 回十分之一度，順序 yaw、pitch、roll。
- 不使用面（TOP／FRONT）常數；聲音在本系列一律改亮燈。
- 軸向與正負號、新增 Python 專案畫面等**待真機確認**，確認前頁面不寫正負號說法。
