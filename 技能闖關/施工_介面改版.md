## 2. 設計方向

### 2.1 色彩（CSS 變數，寫在 common.css :root）
- 背景：`--bg #0b1020`（深藍黑）、面板 `--panel rgba(255,255,255,.04)`＋1px `--line rgba(255,255,255,.08)`＋`backdrop-filter: blur(12px)`
- 文字：`--ink #e8ecf8`、次要 `--sub #9aa4bf`、弱 `--mute #66708a`
- 主強調：`--ac #4cc9f0`（青藍霓虹），成功 `--ok #3ddc97`，警告 `--warn #ffb547`，錯誤 `--bad #ff6b6b`，證書金 `--gold #f5c542`
- 類別色：沿用 設定.json 的 6 色，但調成在深底上夠亮（每類加 `glow` 色給光暈用）
- 背景裝飾：極淡的電路板格線＋2～3 個慢慢漂移的模糊光球（CSS 動畫，`prefers-reduced-motion` 時停止）
- 對比：所有文字對背景至少 4.5:1（施工時用工具檢查）

### 2.2 字型與元件
- 字型維持 Noto Sans TC（標題 900、內文 400／500）；數字用 tabular-nums
- 元件：主要按鈕（霓虹描邊＋hover 發光）、次要按鈕、玻璃面板、技能卡、進度環、徽章、頁碼器、抽屜面板、提示泡泡
- 圖示一律向量 SVG（沿用 sprite.svg，補新圖示），**不用 emoji**

### 2.3 吉祥物「小安」（向量小機器人）
- 一個 SVG `<symbol>`＋分件（頭、眼睛、天線燈、身體、雙手），用 CSS 動畫控制，`Robot.mount(el,{state})` 切換狀態
- 狀態：`idle`（眨眼、天線燈呼吸）、`wave`（揮手，登入畫面）、`think`（歪頭，出提示時）、`cheer`（跳＋雙手舉高，過關）、`oops`（搔頭，做錯時，溫和不嘲笑）、`point`（手指方向，用來指示目前步驟）
- 出現位置：登入畫面（大）、主畫面左下角（小，偶爾說一句提示）、關卡頁提示泡泡旁、過關彈窗
- 頭部跟著滑鼠方向轉一點點（眼睛看游標）＝互動感

### 2.4 類別徽章（6 枚，向量 SVG）
- 每類一枚，造型對應技能（施工時畫，名稱可再改）：
  - A 輸入技能「鍵盤騎士」：盾牌＋鍵帽
  - B 複製貼上技能「分身大師」：兩張重疊的紙＋閃光
  - C 檔案技能「整理達人」：資料夾＋星星
  - D 圖片技能「影像收藏家」：相機鏡頭＋山形
  - E 瀏覽器技能「網路領航員」：指南針＋分頁
  - F 急救技能「電腦小醫生」：十字＋機器人頭
- 共用外框：六角形或圓形徽章底＋類別色漸層＋緞帶寫類別名；**沒拿到**＝灰階剪影＋「還差 n 關」
- 拿到時：過關彈窗多一段「獲得徽章」動畫（徽章旋轉放大、閃光），然後飛進右上角頭像
- 徽章檔放 `_原始碼/badges.svg`（每枚一個 `<symbol>`），新類別要在 設定.json 的類別加 `badge` 欄位並畫一枚新的

### 2.5 動態原則
- 頁面切換：類別換頁用左右滑動＋淡入（250ms）
- 技能卡：hover 微浮起＋外框發光；過關卡片角落有打勾徽章（第一次過關時有「蓋章」動畫）
- 過關：小安 cheer＋輕量彩紙（canvas，1.5 秒）＋徽章飛進右上角頭像（＝「收進個人資料」的意象）
- 全部動畫遵守 `prefers-reduced-motion`

## 4. 技術設計

### 4.1 登入／訪客（app.js）
- `Q.session()` → `{grade,className,studentId}` 或 `{guest:true}` 或 `null`
- 所有頁面載入時：`null` → 導回登入畫面（index.html#login）；`guest` → 不讀寫 Firestore、不寫 localStorage 進度，`recordPass` 回傳 `{guest:true}`
- 類別徽章：`Q.awardBadges()`（和 awardCerts 一樣，條件達成就頒發、永久保留），存在進度的 `badges:{A:{awardedAt, levelSnapshot}}`；firestore.rules 的 `okQuest` 欄位白名單加 `badges`（map，≤ 20 項）
- 拿掉 `Q.initIdBar` 與所有頁面的 `.who` 區塊；`fileUpload` 的改名規則（{grade}{class}{seat}）改讀 session；訪客時改用「1年1班1號」並提示
- 密碼：Firestore 文件加 `pinHash`（SHA-256(年-班-座+密碼)）；**沒有 pinHash＝還在用預設密碼（班級兩位＋座號兩位）**，登入時比對預設值；學生改密碼就寫入 pinHash；後台「重設密碼」＝刪除 pinHash 回到預設。firestore.rules 的 `okQuest` 欄位白名單加 `pinHash`
  - ⚠ 規則改了要請老師重新貼一次 firestore.rules

### 4.2 主畫面類別面板
- `map.html` 改寫：每類一個面板由上往下排；左側快速跳轉列（scrollIntoView）；右下固定總進度元件
- 卡片預覽用 IntersectionObserver 只在看得到時播放

### 4.3 示範游標引擎（新檔 `_原始碼/ghost.js`）
- 每個判定器多回傳一個 `ghost(step)` 函式，給出這一步的動作腳本：
  ```js
  [{move:'[data-ck=passage] mark'}, {down:true}, {dragText:'他發現選取文字其實很簡單。'}, {up:true},
   {keys:['Ctrl','C']}, {move:'[data-ck=f0]'}, {click:true}, {keys:['Ctrl','V']}, {wait:1200}]
  ```
- 引擎在判定器容器上疊一層 `pointer-events:none` 的透明層，畫：
  - 半透明游標（35%，可切 I 字型／箭頭／手指）、點擊漣漪、拖曳時的**假選取色塊**（用 Range.getClientRects 算位置，不動真的 DOM）、按鍵徽章（Ctrl＋C）
  - 不在網頁裡的動作（切分頁、網址列、檔案總管）：游標移到畫面頂端／邊緣＋小插圖（迷你分頁列、迷你檔案總管），配一行字
- 循環：做完腳本 → 停 1.5 秒 → 重來，**一直循環**（老師決定，不因學生移動滑鼠淡出）；這一步完成（tl.next）就換下一步的腳本
- 只在「練」啟用；「闖」完全沒有
- 每個判定器的 ghost 腳本清單（施工時逐一做）：selectText、copyPaste（含 cut）、plainPaste、fileUpload、popup、tabPair、tabUrl、tabReopen、reload、keyTask、quiz、zoom、findWord

### 4.4 技能卡預覽動畫產線（不用手做 GIF）
- 關卡頁加 `?preview=1`：只顯示「練」的判定器、畫面固定 960×540、示範游標**不淡出**連續播放、隱藏其他 UI

## 5.1 模擬桌面環境（2026-10-08 老師追加，優先於 computer use）

> 老師決定：**全部用模擬，除非遇到無法模擬的情境**。不再用 computer use 錄影；教學影片改從模擬畫面用 CDP 自動截圖產生（夜間可做）。

### 目的
同一個技能在不同環境練（遷移）：例如複製貼上要在「網頁文章」「線上文件（類 Google 文件）」「記事本」都做過；挑戰時隨機抽一個環境。

### 外觀與元件
- **桌布**：`_原始碼/桌布.jpg`（老師提供，深藍六角格＋ROKI 貓頭鷹，1696×966），build 時複製到 `site/assets/`。用 `background-size:cover`，重要圖示不要壓在右下角的 logo 上。
- **桌面一開始就有基本圖示**（左上直排）：本機（我的電腦）、資源回收筒、瀏覽器（搜尋引擎）、文件資料夾、記事本；可依關卡加圖示。雙擊開啟對應視窗。
- **工作列**（底部）：開始鈕、已開視窗的按鈕（最小化後點這裡叫回來＝F1 視窗不見）、時間。
- **視窗**：標題列＋最小化／最大化／關閉三鈕，可拖曳標題列移動；外框、圖示、工具列用 SVG，**可選取／可貼上的內容區一律用真的 HTML**（contenteditable／textarea），讓 Ctrl+C／V 是真的。
- **全螢幕按鈕**：模擬畫面右上角有「全螢幕」鈕（用 Fullscreen API 讓整個模擬桌面填滿螢幕，Esc／再按一次離開），可以有多個入口（關卡頁工具列、模擬桌面角落）。
- 應用程式元件（`_原始碼/sim.js`＋`sim.css`）：桌面、工作列、視窗管理、右鍵選單、瀏覽器（分頁列＋網址列＋網頁內容）、線上文件、記事本、檔案總管（資料夾樹、改名、新增資料夾、拖曳、刪除到資源回收筒、還原）、下載列、另存新檔對話框。
- 外觀做「通用版」：版面與操作位置像 Windows／Chrome／Google 文件，**不放 Google、Microsoft 商標**。

### 判定
- 判定器直接讀模擬環境的狀態（檔名、資料夾內容、回收筒、視窗狀態、文件內容），不用學生上傳檔案。
- level.json 新增 `practice.scenes:[{app:'browser',...},{app:'docs',...},{app:'notepad',...}]`；「練」依序換環境，「闖」隨機抽一個。
- 瀏覽器攔不到的按鍵（Win 鍵、Alt+Tab、Win+Shift+S、Ctrl+W／Ctrl+T／Ctrl+N）：改成點模擬畫面上的對應按鈕（工作列、開始選單、截圖工具），或在模擬瀏覽器內攔截可攔的鍵；真的攔不到才保留現有真分頁做法，並在施工日誌記下原因。

## 6. 風險與注意

- **Firebase 還沒開登入**：登入畫面做得出來，但雲端存檔要等老師在 Console 開「匿名登入」；在那之前登入後的紀錄只存在本機。
- 密碼（Q2）只防同學冒用，不是高強度安全；Firestore 文件可被讀到 pinHash，4 位數理論上可暴力猜，國小情境可接受，企畫書要註明。
- 示範游標是「畫出來的假動作」，不會真的複製貼上，學生還是要自己做；要避免影子擋住學生要點的東西（游標層 `pointer-events:none`、透明度 35%）。
- 預覽動畫 18 張同時播放會吃效能 → 一頁只播目前類別（最多 4～5 張），換頁才載入。
- firestore.rules 這次會加 `pinHash`、`badges` 兩個欄位，**老師要重新貼一次規則**，不然雲端存檔會被擋。
- 改版期間學生網址（pcclass/skills）維持舊版，等老師看過說 push 才發布。
